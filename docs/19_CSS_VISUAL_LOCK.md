# 19 — CSS / Visual Lock Notes

The request is intentionally **not** for a modern SaaS-style UI.

## Locked visual traits

- native/classic Windows utility impression
- compact controls
- modest font sizes
- neutral whites/grays
- thin borders
- toolbar icons with labels
- no rounded 20px cards
- no sidebar navigation
- no giant hero area
- no dashboard statistics
- no unnecessary shadows
- no animated transitions for ordinary controls

## Window target

Initial default size should approximate the supplied main-window proportions.

Minimum:
- toolbar must remain usable
- table should get horizontal scroll rather than breaking button order

## Fonts

Use a Windows system stack:
- Segoe UI
- Tahoma fallback
- sans-serif

Keep text close to screenshot scale.

## Dialogs

Classic:
- small title
- grouped controls
- radio buttons
- spinboxes/numeric inputs
- simple footer with OK / Cancel

## Important

"Advanced" means engine capability, **not visual complexity**.
