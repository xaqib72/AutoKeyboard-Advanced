# Reference Folder

These are the user-provided reference materials copied into the handoff pack.

Use them for visual/behavioral understanding.

Reference screenshots and the legacy `.aki` sample are intentionally not distributed in the public source repository. The implementation and written specifications are included instead.

Important:
- do not extract/copy proprietary executable code or embedded application resources
- recreate the UI and behavior with original implementation
- `sample_legacy_workflow.aki` is a behavioral sample; full binary compatibility is not a V1 requirement
